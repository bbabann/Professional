# 류서환 Portfolio

HTML/CSS 정적 사이트 (shadcn 톤, 텍스트 중심). 내용은 모두 placeholder.

- `index.html` 홈 (소개 · Work · Writing · Contact)
- `writing.html` 글 목록
- `article.html` 글 상세 템플릿 (추후 Notion 등에서 가져온 글이 들어갈 자리)
- `style.css` 디자인 토큰(`:root`)과 컴포넌트 스타일
- 폰트: Pretendard/SUITE 비교용으로 `<html data-font="pretendard|suite">` 로 전환

아이콘은 lucide의 라인 아이콘을 인라인 SVG로 사용.
